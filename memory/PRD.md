# Find My Digital Gems (JUJ) — PRD

## Original request
Clone https://github.com/appsumonadi/find-my-digital-gems.git and continue building. Added requirements: local login, checkout with Buy button (Stripe, PayPal, Crypto, Razorpay), seller cabinet for the 3 demo sellers, buyer-only seller reviews, MySQL instead of Supabase (phpMyAdmin-friendly), multi-language (en, ar, fr, ko, id, zh, ru, es) incl. offer titles/descriptions, full admin panel. Host supports Node.js apps.

## Architecture
- TanStack Start (React 19, Vite) Node app in /app/frontend; server functions in src/lib/*.server.ts / *.functions.ts
- DB: MariaDB/MySQL (`juj`), schema + seed + translations in database/juj.sql (single import for phpMyAdmin); preview DB started by scripts/dev-db.sh
- Auth: bcrypt + single JWT session cookie `juj_session` (7 days); roles buyer/seller/admin
- Payments: Stripe (test keys in .env, live); PayPal / Razorpay / NOWPayments crypto coded, shown "Not set up" until keys are in .env
- i18n: src/i18n/<locale>.json (UI, generated by scripts/translate_ui.py); content_translations table (offers/categories, scripts/translate_db.mjs, auto on new offer, admin "Re-translate")
- /app/backend/server.py: helper only (AI translation via Emergent LLM key + /api proxy to the Node app)
